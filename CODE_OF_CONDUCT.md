# Código de conducta

Este proyecto adopta el [Contributor Covenant v2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/).

## Compromiso

Nos comprometemos a que participar sea una experiencia libre de acoso para todas las
personas, sin importar edad, discapacidad, etnia, identidad o expresión de género, nivel
de experiencia, nacionalidad, apariencia, religión u orientación sexual.

## Conducta esperada

- Trato respetuoso y empático; críticas constructivas sobre el código, no sobre las personas.
- Aceptar la retroalimentación con gracia y reconocer los errores.

## Conducta inaceptable

- Lenguaje o imágenes sexualizadas, insultos, acoso, o publicar información privada ajena.
- Cualquier conducta que razonablemente se considere inapropiada en un entorno académico.

## Aplicación

Los reportes se envían mediante un [aviso privado de GitHub](https://github.com/tectijuana/erlang-proyectos/security/advisories/new). Se revisarán con
confidencialidad y se responderá con las medidas que correspondan.
